# WeGram

> **WeGram** — форк [AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop) с фокусом на одну вещь: **Telegram, который работает. Всегда. Без VPN.**

## Миссия

AyuGram — лучший десктоп-мод Telegram (ghost mode, история удалённых, кастомизация; 6,2k ★). Мы берём эту базу и добавляем то, чего нет ни у кого на десктопе: **автоматическое восстановление соединения при блокировках и замедлениях**.

Пользователь не должен знать, что такое «прокси». У него есть одна кнопка: **«Соединить меня»**.

## Дорожная карта «Работает без VPN»

- [ ] **Уровень 1 — Автоподбор прокси** *(в разработке, модуль `ayu/features/connect/`)*
  - загрузка свежих прокси-листов из публичных источников
  - «гонка» кандидатов: проверка каждого на доставку к реальным серверам Telegram
  - автовыбор лучшего + автопереключение при просадке скорости
- [ ] **Уровень 2 — Живой TLS-отпечаток**
  - рандомизация ClientHello в `mtproto_tls_socket` (идея непринятого PR tdesktop#30738): обход блокировок по JA4
- [ ] **Уровень 3 — Встроенный маскировочный мост**
  - внутренний WSS-туннель к ретрансляторам Telegram — соединение поднимается даже при полной блокировке IP-диапазонов

## Структура репозитория

- `upstream-ayugram` — оригинальный AyuGram (источник обновлений)
- `upstream-telegram` — официальный tdesktop (источник обновлений)
- ветка `develop` — наша основная разработка
- `Telegram/SourceFiles/ayu/features/connect/` — модуль «Работает без VPN»
